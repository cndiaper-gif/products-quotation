# Agree (Fujian) Sanitary Products Co., Ltd Product Quotation Calculator

A static customer-facing quotation calculator built from `CBM-upload.xlsx`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to its repository root.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, then select the branch containing these files and the **/(root)** folder.
4. Save. GitHub will provide the public URL after deployment.

No build process, database, or server configuration is required. Product and pricing data are stored in `app.js`; update that file when the quotation workbook changes.
